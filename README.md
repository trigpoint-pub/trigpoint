## Use / 使用

- **Read:** one node per Markdown file, with the original diagram and source notes. Headings work with GitHub's Outline; shelf links preserve the site's reading order.
- **Cite:** use the Trigpoint original URL. To identify this exact copy, also record a GitHub commit permalink. See [citation and version notes](READING.md).
- **Check:** consult the original page for current corrections; use file History and Git diff to inspect mirror changes. [Source records](SOURCES.json) identify this capture.
- **Download:** GitHub's Code menu provides Download ZIP; a clone retains version history once commits are published.

GitHub 的專用部分只提供索引、引用與版本查閱。驗證層、Lab 案例（包括公開試讀）及會員先讀內容留在 [trigpoint.pub](https://trigpoint.pub/)。此 repo 不提供 skills、範本、工具或另一套免費應用產品。

Verification sections, Lab cases including public trials, and member early access remain on the website. Corrections and feedback belong on the relevant original page.
